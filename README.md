# Freshman Mini Projects

This repository collects small programs built around one practical idea at a
time. Each project has its own instructions and tests.

## Projects

- [Position Size Calculator](projects/position-size-calculator): calculates a
  whole-share position from an account balance, risk percentage, entry price,
  and stop price.
- [Log Level Counter](projects/log-level-counter): counts common severity
  labels in a text log and reports lines without a recognized level.
- [Expense Splitter](projects/expense-splitter): divides a bill and optional tip
  evenly while keeping the total exact to the cent.

The projects use standard-library tools where possible, so most can run with a
normal Python installation.
